# Sales-Trend-Analysis
The analysis covers:

Category and Sub-Category Profitability: Total profit was calculated and visualized for each product category and sub-category.

Product Performance: Sales per product and per-unit sales were computed to identify top-selling items.

Customer Insights: Unique customer counts were derived, and the top three customers by purchase volume were highlighted using pivot tables and sorting techniques.

Sales Distribution: Pivot charts were used to display sales across segments (Consumer, Corporate, Home Office), with slicers enabling filtering by Region and Ship Mode.

Regional Analysis: Functions like FILTER, SUMIF, and pivot tables helped explore state-wise sales, identify high-performing regions, and compute average order values.

Revenue Drivers: Sales per order ID were compared against average sales, with conditional formatting used to highlight standout transactions. Category-wise breakdowns were developed using structured tables and lookup functions.

Order Ranges: The number of orders in defined sales ranges was computed using COUNTIFS, providing insight into sales distribution patterns.
